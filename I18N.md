# Internacionalización (i18n)

El runtime usa el español como fuente en `js/i18n.js`, completa las claves inglesas con `js/i18n/en-keys.js` y carga catálogos de frases para 12 locales: inglés, francés, alemán, italiano, portugués, ruso, chino, japonés, coreano, árabe, hindi y bengalí. La presencia de catálogos no sustituye una revisión lingüística ni certifica que todas las pantallas estén traducidas.

## Runtime

- `HF.t(key)` y `HF.tf(key, vars)` resuelven etiquetas y variables en el idioma activo; `HF.tx(text)` localiza literales españoles existentes.
- `js/i18n/phrases.<lang>.js` contiene los catálogos de frases; `js/i18n/en-keys.js` completa claves inglesas. `js/i18n/ui-layer.js` adapta textos y atributos del HTML heredado.
- `HF.localizeGameData()` localiza contenido del juego. Las claves e identificadores (`key`, `id`, `tag`, etc.) no deben traducirse.
- `js/i18n/survey-i18n.js` se genera desde `sql/survey_translations_seed.sql`. Las encuestas pueden recibir etiquetas ya traducidas por la RPC de Supabase; el cliente conserva la traducción de literales como compatibilidad.
- `index.html` carga los packs antes de iniciar la interfaz; `sw.js` incluye esos recursos en la caché `federati-v224`.

## Herramientas

Desde la raíz, con Node.js y dependencias disponibles:

```sh
node tools/i18n_extract_ui.mjs
node tools/i18n_extract_content.mjs
node tools/i18n_build_packs.mjs
node tools/i18n_audit.mjs
node tools/i18n_audit.mjs --strict
node tester_qa/i18n_test.js
```

El test y la auditoría sirven para verificar cobertura; no se ejecutaron en esta revisión porque Node.js/npm no están disponibles en el entorno. Usa `HF.t`/`HF.tf` para texto nuevo e incorpora las claves a los catálogos antes de publicar.
